# 901 班網 v2｜Supabase 連線修正版

這個版本已經修正為目前 901 的 Supabase 專案。

## 你只需要
1. 解壓縮 ZIP。
2. 把裡面的所有檔案直接上傳到 GitHub Pages 專案根目錄。
3. 覆蓋舊版同名檔案。
4. 等 GitHub Pages 更新後重新整理網站。

## 重要
- 網站已連到目前 Supabase 專案，不需要再改 `app.js`。
- 目前資料庫已存在，不要重新執行舊版 SQL。
- SQL 檔僅保留作為備用設定檔；已有資料的專案不需要重跑。
- 後台入口：連續點擊左上角「901」標誌 3 次。
- 後台登入使用 Supabase Auth Email + 密碼。

## 頁面
- `index.html` 首頁
- `members.html` 成員
- `events.html` 活動
- `albums.html` 活動相簿／雲端照片
